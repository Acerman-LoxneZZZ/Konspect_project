# Поля

«Поля» — личная тетрадка для учебных книг. Добавляешь книгу в PDF или EPUB, отмечаешь прочитанную главу и получаешь подробный конспект. Его можно поправить, дополнить своими мыслями и открыть на телефоне, ноутбуке или компьютере. Одна библиотека и одни правки доступны на всех трёх устройствах.

## Старт в новом чате

Открой этот репозиторий как проект и отправь новому агенту:

> Продолжим «Поля» по README этого репозитория. Сначала прочитай README и открой `index.html`, особенно оглавление и главу 4. Возьми макет за основу интерфейса. С учётом навыков из README предложи, как довести первый сценарий от загрузки книги до редактируемого конспекта, который доступен на трёх устройствах.

README и файлы репозитория содержат контекст для продолжения в отдельном чате.

## Как должно работать приложение

1. **Добавить книгу.** Загрузить PDF или EPUB либо указать название и автора. Для книги без файла можно использовать доступный текст главы. Если доступны только фрагменты, интерфейс показывает, что перед пользователем предварительный обзор, и указывает источники.
2. **Выбрать главу.** В тёмной оболочке сначала открывается простой список книг с поиском, затем оглавление. Короткая глава открывается целиком одним нажатием. Для объёмной главы можно раскрыть несколько крупных тем и перейти прямо к нужному месту или читать всю главу подряд. Пользователь может менять предложенные ИИ темы и их порядок.
3. **Читать и дополнять.** Конспект открывается отдельной белой страницей на всю ширину экрана. Внутри — главная мысль и подробный разбор по материалу главы. Сохранять ключевые определения, объяснения, формулы и примеры автора. Для технических книг использовать копируемые блоки кода с выводом, пошаговые расчёты и графики, когда они помогают понять материал. Добавленные учебные примеры подписывать. По важным пунктам указывать страницу или подраздел источника. Пользователь может редактировать конспект, добавлять личные записи и сохранять его в PDF.
4. **Обратиться к ИИ.** Помощник открывается по запросу из конспекта. Он отвечает по книге со ссылками на источник, объясняет выделенный фрагмент и предлагает изменения, которые пользователь может принять. Экран чтения остаётся свободным от постоянного чата и боковых панелей. Для первой версии достаточно статичных схем и рисунков.

## Что уже готово

Актуальный прототип — [`index.html`](index.html). В нём есть переходы от списка книг к оглавлению и конспекту, адаптивная вёрстка, добавление карточки по названию, настройка тем и личные заметки. Глава 1 открывается целиком и содержит схему и расчёт. Глава 3 открывается целиком и содержит два примера Python. Глава 4 разворачивается в четыре темы и содержит формулы, цикл обучения и график ошибки. В главах 3 и 4 можно копировать код и сохранить страницу через диалог печати. [PDF первой главы](assets/grokking-deep-learning-chapter-1.pdf) готов отдельно.

Это статический прототип. Введённые данные хранятся в браузере. Подсказка тем показывает заранее подготовленные варианты. Импорт книг, генерация и редактирование основного текста через ИИ, поиск ответов по источникам, аккаунт и синхронизация предстоит подключить. Стек приложения и способ размещения ещё предстоит выбрать.

## Как продолжить на другом устройстве

Открой `index.html` в браузере. Для локального предпросмотра запусти из корня репозитория `python -m http.server 8000 --bind 127.0.0.1` и открой `http://127.0.0.1:8000/`. Для проверки навигации выбери книгу Эндрю Траска и открой главу 4 или её тему «Цикл обучения на Python».

- `src/reading-room.html` — структура экранов, оформление и взаимодействия.
- `src/technical-chapters.html` — конспекты глав 3 и 4.
- `scripts/build.cjs` — сборка автономного `index.html` командой `node scripts/build.cjs`, без npm-зависимостей.
- `scripts/check.cjs` — браузерная проверка экранов, тем, заметок, PDF и результатов Python. Установка `npm install` и `npx playwright install chromium`, затем `npm run check`. Для Python в `PATH` используется `python`. При необходимости укажи `POLYA_PYTHON` и `POLYA_CHROME`.
- `scripts/make_chapter_one_pdf.py` — исходник PDF первой главы. Для повторной генерации нужны ReportLab и шрифты Georgia и Segoe UI. В Windows скрипт ищет их в системной папке. Для другой папки задай `POLYA_PDF_FONTS`. Готовый PDF уже включён, для запуска макета генерация не требуется.

## Следующий этап

Предложить стек и способ хранения, затем собрать первый рабочий сценарий на одной книге: загрузить файл, выбрать главу, получить подробный конспект с привязками к источнику, вручную изменить его и увидеть ту же версию на другом устройстве. Проверить полноту на объёмной учебной главе по её исходным подразделам. Короткие главы оставлять цельными, а объёмные делить по смыслу. Размер в страницах сам по себе не определяет, нужны ли темы. После этого подключить вопросы по книге и сценарий без файла.
